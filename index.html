Add cards

For a single card, use + Add in the bottom bar. For a batch: one card per line, English | Vietnamese | Tags. Split the parts with a tab, |, = or a dash with spaces round it ( - ). Tags are optional; put several in one card separated by ; (e.g. greetings;cafe). Blank lines and lines starting with # are ignored. Exact duplicates of cards you already have are skipped, and lines that can't be read are left in the box for you to fix.

Settings

Card ages

Progress needed to enter each band. A card starts at 0, gains 1 per pass, and drops back to 0 when you fail it. New isn't listed because it means something different — never reviewed at all.

Mature also sets how hard the picker favours cards you haven't learned yet.

Sync & backup

Merge is the everyday move: it combines this device with the other one — reviews add up, the most recent pass/fail wins, deletions carry across, and merging the same file twice changes nothing. Export from one device, merge it into the other, and repeat in the other direction.

Wipes this device and takes the file as-is. Only for restoring after a wipe.

Sync by copy-paste

If the download or file picker misbehaves (it can on Android when the page is opened straight off the filesystem), move the text instead. Copy here, paste into any notes app or chat with yourself, then paste it into the box on the other device and hit Merge pasted.
